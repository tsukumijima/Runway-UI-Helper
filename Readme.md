# Runway UI Helper

Runway で動画の完成を待っていても、生成に何分かかったのかは画面に残りません。  
**Runway UI Helper** は、Runway のセッション生成画面に生成時間を追加する Chrome 拡張機能です。

完了した動画には実際の生成時間を表示し、生成中の動画には開始からの経過時間を1秒ごとに表示します。  
表示にカーソルを重ねると、開始時刻、終了時刻、タスクの状態も確認できます。

## 使い方

最初に拡張機能をビルドします。

```bash
npm install
npm run build
```

続いて Chrome で `chrome://extensions/` を開き、次の手順でサイドロードします。

1. 「デベロッパー モード」を有効にする
2. 「パッケージ化されていない拡張機能を読み込む」を押す
3. `.output/chrome-mv3` フォルダを選ぶ
4. Runway の生成画面を再読み込みする

コードを更新した場合は、もう一度 `npm run build` を実行してから、拡張機能と Runway の画面をそれぞれ再読み込みしてください。
